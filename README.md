# Shopping Cart

A mock e-commerce shopping cart built with React.

**Live Demo:** [https://shopping-cart-4n6.pages.dev/](https://shopping-cart-4n6.pages.dev/)

## Features

- Browse products fetched from an API
- Add products to the shopping cart
- Increase or decrease item quantity
- Remove items from the cart
- Automatically update cart quantity and total price
- Responsive layout
- Integration tests using React Testing Library and Vitest

## Tech

- **Frontend:** React
- **Build Tool:** Vite
- **Routing:** React Router
- **Styling:** CSS
- **Version Control:** Git & GitHub
- **Testing**: React Testing Library, Vitest

## Deployment

- Cloudflare Pages
